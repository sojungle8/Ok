# 喵喵小窩 🐱

原創的療癒系貓咪收集遊戲（純網頁、零依賴、可加到手機主畫面）。

## 玩法
- **小窩**：點貓咪摸摸 → 好感度＋餅乾；做好的家具自動擺進小窩，提升舒適度
- **貓咪**：用金幣召喚 15 隻原創貓咪（普通／稀有／史詩／傳說），用餅乾餵食提升好感
- **疊疊蛋糕**：點擊時機小遊戲，星數越高，金幣和隨機材料越多
- **工坊**：買家具藍圖、用材料製作家具
- **任務**：每天 3 個每日任務

## 針對同類遊戲玩家抱怨做的設計
| 常見抱怨 | 本作做法 |
|---|---|
| 藍圖不顯示所需材料，買了做不出來 | 購買前就顯示配方、持有數量與缺少的材料 |
| 家具材料來源單一 | 小遊戲依星數掉落**隨機**材料＋任務獎勵＋可直接購買 |
| 每日任務無法完成 | 任務池全部可從零完成，有進度條 |
| 貓咪沒有互動、拿不到餅乾 | 摸摸貓咪就有回饋與餅乾（每日上限 8），餅乾可餵貓 |
| 召喚門檻不透明 | 公開機率、10 抽保底史詩以上，重複貓轉成餅乾 |
