# 你的靈魂動物是？🐾

8 題、30 秒的心理測驗 Web App，內建病毒式分享迴圈。純靜態、零依賴，可直接部署到 GitHub Pages / Netlify / Vercel。

## 病毒迴圈設計
1. 使用者測完 → 產生 **1080×1350 結果圖卡**（IG/Threads 直式比例）
2. 一鍵分享（手機用原生分享附圖片，桌機自動複製連結）
3. 朋友點連結 → 首頁顯示「你的朋友是 🦥 夢想家樹懶，你們合得來嗎？」→ 引導自己測
4. 結果附「最速配動物」，促使使用者再轉給朋友比對

## 執行
```bash
npm start      # http://localhost:8080（ES module 需經 HTTP 開啟，不能直接雙擊檔案）
npm test       # 邏輯單元測試（窮舉全部 256 種作答組合）
```
