# 😇 不當慣老闆模擬器

開一間台灣街頭的小店：自己擺設、自己排班、自己定價。讓客人吃飽、員工開心，還要記得付房租。

**破關**：撐滿一年（48 週）沒有被收店就算破關，會依評價、慣老闆指數、員工心情、一年淨利、分店和獎項打分數（🥇 120 分以上、🥈 85 分以上、🥉 50 分以上），之後可以繼續經營第二年。

沙盒經營遊戲，沒有時間限制。難度分成🌸 新手、🌱 輕鬆、一般、🔥 地獄；

**🤖 經營小幫手**（新手、輕鬆預設打開，💡 店長建議或 ☰ 選單可以開關）：不熟經營遊戲也能玩。小幫手會在客人等到生氣、人手又不夠時幫你招人（每個服務位都有人了，就提醒你該買設備）、把薪水調到行情、關心心情不好的員工、買休息桌和夏天的冷氣、物價漲了就調價格、生意好卻虧錢時小漲 5%、太髒就請人大掃除；事件放太久會照「好老闆」的方式幫你處理。每做一件事都會用藍色訊息告訴你。完全不操作、只靠小幫手，六種產業在新手和輕鬆模式都能撐滿一年拿到獎牌。

**事件可追溯**：事件會挑對人（離職代辦只會是剛來的新人、「新人沒人教」只會發生在剛到職的人身上），有人離開時結果畫面會寫出是誰、職位、到職多久、為什麼大家心情會掉；「帳本」最下面有事件紀錄（誰處理的、有沒有逾時）。颱風選擇放假，店當天真的會停業。上方時間狀態會分開寫「⏸ 暫停／▶ 速度」和「營業中／休息中」，打開任何面板都會暫停。

**評論與評價**：評價＝最近 100 則評論的平均；評論面板會統計三星以下的原因（排太久、價格、服務態度、太熱、衛生、賣完了……）並告訴你怎麼改善，也可以只看低分評論。

**更多判斷**：一般客訴不一定是奧客——有時候真的是店裡做錯（道歉補償最好，硬挺員工會被留一星），有時候是客人誤會（好好說明最好）；奧客和客訴的選項順序每次都會打亂。員工吵架的原因和結果會變，同一對吵第二次以上，私下調解效果變差，可以送去上團隊溝通課或請店長處理。

**升遷流程**：升組長建議到職 2 週、技能 50 以上；試用期滿 14 天會跳出評估（帶班前後的同事心情、客人生氣率），可以正式任用、延長試用並上主管課，或不傷感情地降回原職。「再觀察兩週」之後再來問，會看到這段時間進步了多少。不想帶人的老手可以升「資深」（技術職，時薪 +$15）。

**後期經營**：週報和帳本會分開列本店和分店的損益；分店卡片顯示上週想來多少人、服務多少人、流失多少人、容量用了幾成；分店兩間以上要付總部管理費（有分店店長的省一半）；分店士氣、評價變差會先亮警告，撐不住會打電話求救，也會遇到房東漲租、設備故障。拿到金獎之後還有長期目標：五星連鎖、店長養成所、一週淨賺五十萬、全公司都想待、老字號。

**各行各業的用語**：同一句話會換成這一行的說法（出餐／出杯／剪髮／修車／結帳、好吃／好喝／剪得好看、送小菜／送免費洗頭／送免費打氣、果菜批發市場／美髮材料行／機車零件批發／物流倉庫……），小編貼文、評論、事件、陰謀、聯名都會跟著換；只有餐飲才會遇到的奧客、事件、聯名不會出現在理髮店和機車行。各行也有自己的裝潢：紅燈籠、打卡牆、旋轉燈柱、雜誌架、輪胎牆、安全帽架、愛心傘架。

右上角的 💡 店長建議會列出現在最該處理的事，按「前往」直接打開對應的面板。打開員工、庫存、經營這些面板時時間會自動暫停，快轉中有人找你也會先調回正常速度（選單裡可以關掉）。每天打烊後自動存檔。只要**慣老闆指數到 100**（上新聞），或是**現金是負的又借不到錢**，店就會收起來。

直接用瀏覽器打開 `index.html` 就能玩（3D 畫面需要連網載入 three.js）。第一次玩會有一步一步的新手教學。

## 怎麼玩

**店面是一個 3D 的台灣街景**：騎樓、停在路邊的機車、隔壁店家的鐵捲門、你的招牌。拖曳移動視角、滾輪（或兩指）縮放、Q／E 旋轉；靠近鏡頭的牆會自動降低。天色會從白天變黃昏，晚上街燈和招牌會亮。

**客人是真的走進來的人**：路過的人會依照評價、價格、店面漂亮程度、乾淨程度決定要不要進來；進來後點餐、排隊、被服務、付錢（頭上跳出金額），可以內用的店會找位子坐。等太久會生氣離開，留下一星評論。

| 客人 | 什麼時候來 | 個性 |
| --- | --- | --- |
| 🎒 學生 | 上學前、放學後（暑假早上比較少，開學季變多） | 預算有限，價格太貴就不來，偏好便宜的品項 |
| 💼 上班族 | 早上通勤、午休、下班 | 趕時間沒耐心，但不太在意價格；週末很少 |
| 🧓 長輩 | 一大早、上午、午後 | 很有耐心，喜歡愛聊天的店員，覺得貴就不來 |
| 🙂 一般客人 | 整天都有，週末最多 | 平均 |

理髮廳長輩多、機車行上班族多、手搖飲學生多。

**員工有自己的想法**：每個人有個性（勤勞、愛聊天、新手、老手、玻璃心、吃貨、夜貓子、開朗）、技能、心情、精力、飽足感。累了會自己去休息區；沒有休息區只能站著撐。頭上會冒出想法：「好累……」「加班費到底有沒有……」「老闆人很好」。點員工可以加薪、稱讚、罵人、叫他先下班、資遣。

**食材庫存**：每種品項會用掉對應的食材（早餐店的蛋與餅皮、麵店的牛腱肉、手搖飲的珍珠與鮮奶……）。每天開門前送貨員會騎車把貨搬進來，補到你設定的進貨量；生意變好就會賣完，客人只能改點別的或直接走，這時可以叫急件（貴三成、約 40 分鐘到）。叫太多也不行：珍珠、鮮奶、青菜隔夜會報廢一部分。

**清潔與衛生稽查**：客人吃完、下雨天的泥巴、剪下的頭髮、機油都會留在地上，員工沒客人的時候會自己拿拖把打掃，打烊後也可以留下來打掃；但油垢會慢慢累積，只有請清潔公司大掃除才清得掉。衛生局（機車行是環保局）的稽查員會不定期走進店裡繞一圈：80 分以上拿「優」、門口貼標章；不到 60 分會被要求限期改善，複查還不及格就罰錢、上新聞。稽查員進門時可以喊「大家先打掃」。

**競爭對手**：生意做起來之後，隔壁可能開一間同業（開幕還會送花籃、辦買一送一），會搶走一部分客人，也會開更高的時薪挖角你的員工。評價、價格、乾淨程度決定客人選誰；可以發傳單、辦九折優惠週、印集點卡。撐得夠久，對方可能會撐不下去收起來。

**勞健保與稅**：薪水之外，雇主還要負擔勞保＋就保（約 8.9%）、健保（約 4.8%）和勞退提繳 6%；不保會被勞檢開罰。營業稅依月營業額：沒到起徵點免徵、小規模營業人 1%、超過 20 萬要開統一發票並繳 5%（銷項減進項）。

每週結算一次（週報），每四週是一個月：物價、市場時薪會上漲，4 月和 10 月電價審議，6～9 月是夏月電價。

**台灣生活感**
- 天氣：晴天、炎熱、陰天、寒流、下雨、颱風。下雨天客人少、外送多，路人會撐傘；颱風天要決定要不要營業。
- 節慶：過年前（大家要剪頭髮、保養機車）、春節連假、母親節、端午、中元普渡、開學季、中秋烤肉、跨年。國定假日出勤，工資自動加倍。
- 外送平台（早餐店、麵店、手搖飲）：外送員騎著有外送箱的機車來取餐，訂單比較大，但平台抽成 30%。

**🕹️ 老闆下場**（右下角按鈕，或 G 鍵）
- 自己操控老闆（腳下有金色圓圈、頭上寫「你」），鏡頭會跟著走。電腦用 WASD／方向鍵，手機用左下角的搖桿；也可以直接點地板走過去。
- 走到東西旁邊按 E（手機按右下角的按鈕）互動；附近有好幾樣東西時會跳出選單讓你挑：
  - 員工：聊天、稱讚、請飲料、叫他休息、罵人（走近時員工會「突然變得很認真」）
  - 客人：打招呼（多一點耐心）、招待一份小菜（評價更好）；奧客：當場出面嗆或物理超度
  - 地上的髒污：自己拖地
  - 空著的櫃台：親自顧店，客人過來你就幫他服務（會消耗老闆體力）
  - 騎樓的路人：發傳單，有機會把他拉進來吃
  - 路邊：騎上機車在街上兜風；隔壁對手的店：走進去探班
- 走到街的盡頭（或按 M／🗺️ 出門）打開城市地圖。夜市、廟、夜店、批發市場和隔壁對手的店都是**可以走進去的 3D 場景**：畫面會切到那裡，一樣用 WASD／搖桿（或點地板）走，走到攤位或人旁邊按 E 互動，走到綠色圈圈的出口回店裡，回來會跳出這趟的總結。老闆在外面時店裡照常營業，事件一樣會跳出來。
  - 🏮 夜市：雞排、臭豆腐（補體力）、幫在班員工買珍奶、算命（這幾天客人 +3%）、射氣球、套圈圈、遇到認出你的熟客
  - 🙏 廟裡：上香、擲筊三次（離開時聖筊越多這幾天客人越多）、抽籤詩、添香油錢、跟廟公聊天
  - 🪩 夜店（入場 $500）：跳舞漲粉絲（耗體力）、吧台、跟 DJ 點歌、跟大學生聊天（多一個應徵者）、遇到隔壁老闆可以請他喝一杯（對手記仇 -1）
  - 📦 批發市場：每一攤補一種食材（八五折），先跟阿伯殺價成功就變八折
  - 🏪 隔壁對手的店：試吃、偷看廚房（臥底）、跟店員聊天（挖角）、在他門口發傳單，當場就知道結果
  - 健身房（之後顧店比較不累）、銀行還是出門一段時間再回來。

**🕵️ 陰謀計畫與 🤝 聯名合作**（城市地圖的「徵信社」「商圈聯誼會」，或成長分頁的對手卡片、探班之後）
- 對付隔壁的十種計畫，每一種都標明成功率、被抓包的機率和合不合法：在他門口發傳單、挖角他的店員、戴墨鏡去臥底偷學招牌（成功的話你的招牌會變好吃）、送他一隻只會說「隔壁比較好吃！」的鸚鵡、找親戚去排隊不點餐、叫朋友把機車停滿他門口、花錢請網紅說他「普普」、在爆料社團散播謠言、檢舉他違規、請算命師去他門口嘆氣。
- 違法的被抓到會罰錢、上新聞（附法律小知識）；對手會記仇，記仇越深越容易報復——在你門口擺充氣人偶、刷你一星、送你一隻會罵「慣老闆」的鸚鵡。報復時可以選擇忍下來、帶伴手禮去談和，或繼續對幹。
- 聯名合作：阿伯水餃（蛋餅包水餃限定套餐）、全都福眼鏡（「看清楚價格，我們很便宜」）、健身房、補習班（考前衝刺套餐）、寵物美容店（毛孩友善日）、在地宮廟（廟會平安餐）、獨立樂團（騎樓小型演唱會）、在地美食網紅（清楚標示的付費合作），甚至可以跟隔壁對手「世紀休戰聯名」，休戰期間對方不搶客人。聯名期間來客增加，也會吸引特定類型的客人；評價越高越容易談成。
- 不管是陰謀還是談合作，都是老闆親自出門去辦，要花遊戲時間，回來才知道結果。

**員工活動與互動**（👥 員工 →「🎉 活動」）
- 員工聚餐（熱炒、吃到飽火鍋）、夜店狂歡、KTV 唱通宵、密室逃脫、員工旅遊、下午茶、尾牙抽獎，可以自己挑誰參加。每個人依個性喜好不同：夜貓子愛夜店、吃貨愛火鍋、玻璃心和老手不愛夜店；一起玩過的人交情會變好，本來處不來的也可能在舞池裡和好。活動中會發生插曲（被 DJ 點名上台、老闆唱〈愛拚才會贏〉變成員工群組的鬧鐘），夜店和 KTV 隔天可能有人宿醉請假。
- 也有「下班後『自願』心靈成長課」：不給薪、全員都要到，員工心情大跌、慣老闆指數上升，還可能被發到網路上。
- 個人互動（總覽每一列按「⚙️ 設定」）：聊天談心（員工會說出他的煩惱或生活趣事）、請喝飲料、送去上課（技能 +10）、主管培訓、升組長／店長、降職、派去分店當店長。

**👑 升遷與主管**（員工 → 主管分頁，一眼看完店長、組長、潛力名單和分店店長）
- 每個人都有看不到的**領導力**和**企圖心**：面試和同事印象只看得到「領導力 ★★★☆☆？」和一句同事評價（大概七成準）。技能好不一定會帶人（彼得原理）。
- 升上去三天後才揭曉他是哪一種主管：🤗 暖心型（同事心情好、排隊客人比較有耐心）、🪖 鐵血型（做事變快但心情被壓著，玻璃心的人更受不了）、🎓 教練型（同事技能長得快）、🧮 精算型（食材報廢變少）、🐟 摸魚型（自己反而變慢）。效果看領導力，店長再放大 1.5 倍。
- 升職後有 14 天試用期，試用期內降職不傷感情；過了試用期降職，心情大跌、慣老闆 +1。組長每 3 個員工 1 位，店長全店 1 位。
- 企圖心高的人做滿兩週會主動來要求升遷，一直拖會跳槽；企圖心低的人被升上去壓力很大。跳過資深員工升新人，資深的會不爽。
- **店長代理處理事件**（可關）：你來不及處理、或出門在外時，在班上的店長會照他的風格幫你做決定（鐵血型領導力低的話，可能替你做出慣老闆的選擇）。
- 主管事件：員工投訴鐵血主管（找他談可能改成暖心型）、抓到摸魚主管、心情差的店長被對手挖角還帶走好朋友。
- 分店店長：派一位員工去分店（他會離開本店），分店的士氣、評價、容量或食材成本會照他的風格和領導力變化，也可以調回本店。
- 👊 **物理超度**：遇到奧客和騙子時可以選擇動手，結果看運氣——可能被封為「騎樓戰神」爆紅，也可能賠醫藥費、被告傷害罪上新聞，或是一出手就閃到腰。（只能對奧客和騙子用；對員工動手是職場暴力，不在選項裡。）

**員工人際關係**：一起上班的同事會慢慢變成好朋友或處不來。好朋友同班心情比較好；合不來的會吵架，要你出面調解或把他們排開；感情很好的可能會在一起；好朋友離職，留下來的人也會難過。

**笑料與時事**

- 📱 **小編蹭時事**：每週都有新的網路時事（電動跑車發表會、家具大廠小編蹭時事爆紅、颱風假之亂、雞蛋漲價、演唱會搶票、AI 取代人類、薪水凍漲……）。用「開頭＋內容＋結尾」拼一篇貼文，蹭剛出來的時事最紅，同一種內容一直發大家會膩；拿災難或選舉開玩笑、盜用梗圖會被炎上。爆紅會帶來粉絲和客人，網友留言也會跟著出現。

**長期目標**
- 店家等級：賺的毛利越多經驗越高，升級解鎖高級設備（雙層大煎台、自動煮麵機、自動茶飲機、電動理髮椅、油壓升降台、自助結帳機）、更多裝潢和更大的店面。
- 展店：Lv.5 之後在「🏙️ 成長 → 選地點開分店」自己挑地點和店面大小。十二個地點的人潮、房租、客群都不一樣（觀光區假日爆滿、商辦區週末冷清、學區寒暑假淡季……），客群跟產業合不合看「適合度」星星，會先估算每週營收、成本和淨利；小店便宜但容量小，大店貴、房租高但吃得下更多人，開了之後也可以再擴建。每間分店都看得到店面，可以調時薪（低於行情／行情／高於行情）、定價、人手、改裝；人手不夠或薪水太低，分店員工士氣會掉、評價會跌，還可能上網爆料。
- 年度好店評選：每年 12 月最後一週頒獎，金銀銅獎有獎金；慣老闆指數太高會被網友票選為「年度慣老闆」。

**打烊**：最後一個員工走出店門，鐵捲門就會拉下來；早上第一個員工來上班時再拉起來。

**音效與音樂**：收銀機的叮聲、進門門鈴、客人生氣、事件提醒、升級、鐵捲門，還有街道背景音和雨聲。背景音樂有六首（早上、午後、尖峰、晚上、雨天、打烊後），會跟著時段、天氣和店裡有多忙自動換曲；全部用瀏覽器即時合成，右上角可以分別關掉音樂和音效。

**存檔**：有三個存檔格，每天打烊後自動存檔；可以匯出成 JSON 檔案帶到別的裝置，再從開始畫面或選單匯入。

**畫質**：選單裡可以選自動／高／中／低。手機預設中畫質；自動模式下如果畫面持續低於每秒 26 幀，會自動調低（關陰影、降解析度、減少雨滴和路人）。

**手機省電**：畫面最多每秒 60 幀（低畫質 30 幀，120Hz 的手機也不會多畫一倍）；暫停、看對話框又沒在操作時降到每秒 12 幀。中、低畫質不用毛玻璃（它每一幀都要重新模糊 3D 畫面），彩帶和金幣跟著畫質減量；高解析度觸控螢幕不開反鋸齒。靜態場景的馬路標線、時鐘刻度、鴿子身體都合併成一個網格，所有人腳下的影子用一次繪圖畫完，後期大店的繪圖次數少了一成多。

**慣老闆指數**會因為這些事上升：加班不給加班費、不排休（七休一）、不准休息、沒有休息區、薪水低於行情、罵員工、事件裡選了慣老闆的選項。指數越高越容易被勞檢罰錢。

## 📜 章節任務：玩法一章一章開

一開始只有顧好一間店。完成每一章的任務（左下角的任務小卡，點開看進度）就拿到獎金和經驗，並解鎖下一批玩法，不會一開局就塞一大堆系統。舊存檔會直接解鎖已經玩到的部分。

| 章節 | 任務（摘要） | 解鎖 |
| --- | --- | --- |
| 🌅 第一章：開張大吉 | 撐過第一週、評價 4.0、第一篇貼文、5 個員工 | 👑 主管系統 |
| 🌱 第二章：站穩腳步 | Lv.5、升一位主管、連續兩週賺錢、衛生「優」或 4.3 星 | 🏙️ 開分店、🔀 斜槓員工、🍂 季節限定 |
| 🏙️ 第三章：連鎖之路 | 第一間分店、派分店店長、推一次季節限定、Lv.10 | 📋 授權制度、🗺️ 區經理、🏬 分店店型 |
| 🏭 第四章：規模化 | 3 間分店、設定授權規則、任命區經理、單週淨利超過開店資金的六成、Lv.15 | 🏭 中央廚房、🤝 加盟 |
| 🌏 第五章：品牌 | Lv.20、分店＋加盟 6 間、中央廚房、連續 12 週沒被罰 | 🛤️ 第二幕：選路線 |

**第二幕有兩條路，各有自己的結局**：
- 🔔 **上市上櫃**：公司估值夠高就能找投資人（拿到大約一年本業獲利的資金，之後投資人每週分走一部分獲利），之後每季要達成董事會的淨利目標；董事會會叫你砍人事成本，照辦數字好看、但慣老闆指數上升。連續 3 季達標、慣老闆指數低於 20 才能敲鐘。
- 🤲 **員工持股・百年老店**：拿出一筆股份分給員工，大家的心情每週慢慢變好、分店士氣更穩；讓本店和所有分店士氣都到 80、培養出 5 位店長，再從領導力 70 以上的人裡指定接班人。

**解鎖的玩法**：
- 🔀 **斜槓員工**：約三分之一的應徵者有副業，各有一個好處和一個麻煩：外送員（做事快、會想早退去跑單）、直播主（貼文更多讚、會在店裡偷開直播）、研究生（學得快、考試要請假）、樂團鼓手（晚班不累、演出要調班）、補教助教（學生客人比較喜歡）、接案設計師（貼文更好看、截稿日會恍神）。每個人還有兩幕的人生故事：第一幕你怎麼選，決定三週後第二幕發生什麼（加薪留人後辭掉外送專心學、出車禍要不要給慰問金、直播爆紅辦粉絲見面會、畢業了要不要給正職、要員工免費幫你設計之後他去幫對手做……）。
- 🍂 **季節限定**：到「經營」推出當季限定品（依產業和季節不同，例如手搖飲的冬季是黑糖薑茶、機車行是寒流電瓶健檢），四週內客人 +12%，分店 +6%；同一個品項連續推效果會變差。
- 📋 **授權制度**：在「員工 → 主管」設定哪些事交給店長或區經理處理（客訴、奧客、吵架、分店狀況、其他小事）和單件預算上限。他們只會選預算內、不傷員工的選項；升遷、外人上門的事一定會問你。
- 🗺️ **區經理**：從分店店長裡挑一位升上去，所有分店每週士氣更穩、總部管理費 -30%，也能在你不在店裡時代你處理授權的事。
- 🏬 **分店店型**：開分店時選車站快取店（來客多、員工累）、社區店（房租便宜、熟客多）、觀光旗艦店（高價不掉客、房租貴）。
- 🏭 **中央廚房**（非餐飲業是物流中心）：本店進貨成本 -10%、分店 -15%，但偶爾會出包（冷藏溫度異常、瑕疵品），一出事所有店一起受影響；可以全面回收、切換事先簽好的備援廠商，或賭一把照常出貨。
- 🤝 **加盟**：收加盟金和 6% 權利金，不用自己出錢展店；但面談印象不一定準，苛待員工的加盟主被爆料時，網友會把帳算在你的品牌上（輔導改善、解約、或說「那是他的店」）。

**等級上限 Lv.40**：Lv.11 以後主要靠分店和加盟升級，每幾級有一個獎勵（應徵者更多老手、活動和研發打折、客人更有耐心、評價計算時老客人幫你說話……），也會解鎖新的店面和高級裝潢：旗艦店面（Lv.15）、牆面彩繪、LED 跑馬燈、設計師吊燈、植生牆、藝術裝置、招待機器人，以及 Lv.24 的創辦人銅像。

**每一級都有東西拿**：Lv.2～10 主要解鎖設備和店面，Lv.11 以後每一級都有一個看得到的經營效果（貼文漲粉、急件加價變少、新分店開幕期縮短、罰款變少、加盟主素質更好、改裝費打折、中央廚房更省、所有店來客 +3%、季節限定多賣一週、老闆壓力變小、估值提高……）。每 5 級換一個店家稱號（路邊小店 → 巷口名店 → 在地人氣店 → 排隊名店 → 連鎖品牌 → 傳說中的老闆 → 國民品牌 → 業界傳奇 → 台灣之光），換稱號時店裡辦小慶功（員工心情 +5、大家喊「升級了！」）。升級時招牌會閃、跳出升級卡片（列出這次拿到的東西和下一個獎勵，點了直接看等級路線圖）；「成長」分頁有接下來四級的路線圖。

**節奏**：Lv.25 大約第一年、Lv.30 大約一年多、Lv.40 要撐到第二幕後段（強的路線大約第 1000 天）。

**結果畫面的小知識分三種**：有法律依據的標「📘 法律小知識」（勞基法、食安法、公平交易法、刑法……），防詐騙的標「🛡️ 防詐小提醒」（165、冒名、假物流），單純的經營建議標「💡 經營小撇步」（怎麼安撫客人、怎麼留住人），不會再把建議標成法律。

**紀錄只保留最近幾個月（遊戲時間）**：每週帳本留最近半年（26 週），評論和事件紀錄留最近三個月；整年的淨利、最佳單週這些需要的數字另外記成精簡的一串，存檔不會越玩越大。

**店名**：每個產業的預設店名都是虛構的（可以惡搞，但不會和真的店家一樣），開店畫面按 🎲 可以隨機換一個惡搞或時事梗的店名。

**畫面**：晚上路燈和店門口會在地上灑出暖色光暈，畫面會隨時段微微調色（清晨、黃昏偏暖，晚上偏藍、四周微暗）；對街有人行道、行道樹、斑馬線和公車站牌（鏡頭轉到街上那一側時會自動藏起來）。介面的浮動面板改成毛玻璃，按鈕和進度條更有立體感。

**鏡頭與互動**：鏡頭可以任意角度旋轉（右鍵拖曳、Shift＋拖曳、兩指轉動）、調整俯仰（上下拖曳）、雙擊地板拉近、⌖ 回到預設。街上有車流（晚上開頭燈）、會被嚇飛的鴿子、牆上的時鐘跟著遊戲時間走。每筆收入會有金幣飛進右上角的現金；連續好幾位客人都滿意會累積「🔥 連續好評」，到 10、25、50 位有獎勵。點員工可以 💪 加油，點客人可以打招呼、招待小菜。

## 🛠️ 生財設備：每一樣都看得出是什麼、也都有用

每個產業除了基本設備，還有 4～5 樣專屬的生財器具（建造 → 生財設備）。每一樣都有自己的 3D 造型（鍋就是一口冒煙的大鍋、輪胎平衡機側邊掛著一顆輪胎、霜淇淋機頂上有一支霜淇淋），前面還貼著名牌。

| 產業 | 器具 | 作用 |
|---|---|---|
| 🍳 早餐店 | 鐵板麵專用爐、吐司烤箱、現磨豆漿機、外帶取餐窗口、雞蛋冷藏架 | 分擔煎台、做得快；自己磨豆漿省原料；外帶窗口吸引路人；蛋和餅皮少報廢 |
| 🍜 麵店 | 熬湯大鍋、滷味櫃、製麵機、冷藏展示櫃 | 牛肉便宜、牛肉麵評價更好；小菜快又吸引人；麵條省料；小菜少報廢 |
| 🧋 飲料店 | 自動封口機、珍珠專用鍋、鮮果吧、製冰機 | 每一杯都快一點；珍珠少報廢、珍奶評價好；果茶分出去做；夏天多吸引客人 |
| 💈 理髮店 | 燙染區、烘罩機、雜誌報紙架、美髮商品櫃 | 燙染不佔剪髮椅、燙染更快；等候的客人更有耐心；路人進來看 |
| 🛵 機車行 | 輪胎平衡機、行車診斷電腦、洗車區、機油桶架、雜誌報紙架 | 補胎專用；保養更快更準；美容分出去；機油便宜 |
| 🏪 超商 | 熱食櫃、義式咖啡機、霜淇淋機、冷凍櫃、雜誌書報架 | 便當關東煮不塞收銀台；咖啡更好喝；冷凍櫃吸引人、商品少報廢 |

同一種效果（省料、減報廢）買兩台不會疊加，取最好的那台。

兼營業務的 31 種設備也都有專屬造型：ATM 是藍色提款機、彩券是紅色櫃台加「彩」字牌、投幣洗衣是上下兩台圓窗洗衣機、雞排有油炸鍋和保溫燈、寵物修剪的美容桌上站著一隻小狗、二手車買賣是展示台上的機車掛著價格牌、電池交換站亮著綠燈……

## 🚓 街頭時事

店門口的馬路偶爾會上演新聞裡的事：毒駕的車蛇行飆過、警車鳴笛追（有時就在店門口被攔下來押走，偶爾會擦撞騎樓的機車，要你決定監視器畫面怎麼處理）；晚上路口臨檢（騎車的客人和外送員變少，走路的客人覺得比較安心）；清晨騎樓有人倒地抽搐、旁邊掉了一支電子煙——這是緊急狀況，正確做法是打 119、讓大家退開，拍下來上網會被罵。

## 🧰 兼營業務：在台灣，每一行最後都會被逼成十項全能

到「建造 → 🧰 兼營業務」買小設備，就能多做一項生意。它們會帶來**額外**的客人（不搶本業），有些客人辦完事還會順便買東西。客流量是校正過的：在「客群普通」的店，扣掉員工時間，設備大約 6 週回本。

**不是每種兼營都適合每間店。** 每項業務都有主要客群（掏耳朵靠長輩、肩頸按摩靠上班族、聯名周邊靠學生），會照你店裡真正的客群比例（產業、營業時段、裝潢風格、聯名活動）算出 1～5 顆星的「適合度」，直接乘在客流上（約 0.45～1.5 倍）。另外，坐著做很久的服務在小店面會很擠；有些業務會互相干擾（寵物修剪的狗叫聲 vs 掏耳朵和按摩、雞排油煙 vs 甜點和水果杯、洗車 vs 代辦驗車）；寵物友善店開寵物修剪則有加成。買設備前，建造清單會直接顯示星等和原因。

| 產業 | 兼營業務 |
| --- | --- |
| 🏪 便利商店 | 包裹店到店、ATM、影印傳真、熱狗、多媒體售票機、行動電源租借、彩券、投幣洗衣 |
| 🍳 早餐店 | 代收社區包裹、中午加賣便當、精品手沖咖啡、親子早午餐 |
| 🍜 麵店 | 外帶滷味、便當外帶、網路團購冷凍水餃、年菜代訂（只有 1、2 月） |
| 🧋 手搖飲店 | 雞排炸物、甜點冰品、現切水果杯、聯名周邊 |
| 💈 家庭理髮廳 | 掏耳朵、洗髮精販售、肩頸按摩、剪髮捐贈（做口碑）、寵物修剪 |
| 🛵 機車行 | 雨衣安全帽、代辦驗車過戶、機車美容、二手車買賣、機車出租、電池交換站 |

**員工也被逼成十項全能**：沒學過的業務做得慢、做久了才會自己學會；可以花錢送去上課。店裡的業務比員工會的多太多，大家心情會變差，還會有人來問「我們到底是什麼店？」。每項業務都有自己的事件（包裹爆倉、ATM 前的詐騙電話、演唱會開賣、頭獎開在你家、泡水車……），選擇會留下後果。

## 🚪 後場：儲藏室、員工休息室、老闆辦公室、廁所

到「建造 → 🚪 後場」蓋在店面後方（後牆最右邊那一格是門，不要擋住）。每個房間三級，轉到店的背面就看得到裡面。

- **🗄️ 儲藏室**：決定貨量上限（太多放不下要退貨）和隔夜報廢；包裹、團購、年菜這類業務要有倉庫才做得大。事件：老鼠、盤點對不上、過期品。
- **☕ 員工休息室**：員工到後場休息，恢復更快、心情更好；最高級的口碑會讓來應徵的人素質更好。
- **💼 老闆辦公室**：關起門來罵人不會影響其他人、稱讚更有效；面試間看人更準；保險箱防盜，老闆也能進來休息。
- **🚽 廁所**：內用客人會去上（沒有廁所有些人會給低分），用一次髒一點，閒著的員工會去打掃（都叫同一個人洗，他會來抗議）。可以開放路人借廁所，有些人借完會順便買東西。升級到免治馬桶網美廁所，客人會打卡。事件：馬桶塞住、有人抽菸、睡著、衛生紙被偷、水管爆裂、廁所文學、外送員借廁所。老闆下場時可以親自洗廁所。

## 🐾 寵物

最多養 3 隻：店貓、店狗、鸚鵡、招財龜，各有個性。寵物越開心越能吸引客人、員工心情越好（店狗還會讓排隊的客人比較有耐心）；但每天要飼料錢、要看獸醫，餐飲業養寵物稽查會扣分（裝圍欄可以降低），對貓狗過敏的客人和員工會不開心，鸚鵡還會學老闆罵人。也可以打開「寵物友善」：帶毛孩的客人會來、常順便買點心，但會有狗打架、尿尿、過敏客人抗議。

## 🎨 裝潢

裝潢沒有上限，但效果遞減：便宜的盆栽一開始很划算，高級裝潢佔一樣的格子、效果更大。店越漂亮，客人越能接受高一點的價格。同一種風格（🏮台味復古、🌿文青、📸網美、🤖科技、🛋️溫馨）放 3 件以上就會成形，吸引特定客人、各有一個額外好處；兩種風格都很多又不夠突出，看起來會很亂。裝潢放久了會舊（翻新可以恢復），每隔一陣子某種風格會流行。本店的門面也會讓分店的評價沾光。

## 🧑 人生篇章

老闆自己也有人生：**壓力**來自自己處理的事件、沒人處理的事件、全年無休、客人生氣、沒有店長的分店；授權、區經理、公休、度假、家庭會讓它降下來，壓力太大會生病住院（店就交給大家了）。分紅領出來的「老闆個人財富」可以拿去健身、買車、買房、出國度假、帶爸媽出國、給孝親費、捐款、念 EMBA，每一項都會影響遊戲；房貸、保母費不夠付時會挪用公司的錢。還有相親、結婚、生小孩、孩子的表演、爸媽住院、同學會、朋友借錢、投資詐騙、健檢紅字、房東賣房、壓力爆表這些人生事件，以及人生里程碑。破關和第二幕結局時，除了店經營得怎樣，也會看你自己過得怎樣。

## 💰 金錢平衡

- 分店的開店成本依產業校正：最好的地點大約 36 週回本，一般地點一年多；剛開幕的前 8 週是「新店期」，客人從五成慢慢爬滿。
- 加盟金和權利金比較低，加盟店數上限是直營分店數＋1，還要扣總部督導成本。
- 投資人只會給大約一年本業獲利的資金，之後每週分走兩成五的獲利；上市募得的資金也差不多是一年獲利，上市後每週分一成五給股東。

### 新增產業或設備

在 `js/industries.js` 加一個產業（品項、尖峰時段、預設擺設），再到 `CATALOG` 加它用的設備：`serves` 是能做的品項，`staff`／`cust` 是店員和客人站的位置（以設備正面為前方的相對座標）。3D 模型在 `js/shop3d.js` 的 `MODELS` 裡用方塊和圓柱拼出來。
