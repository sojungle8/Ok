# 😇 不當慣老闆模擬器

你是一間公司的老闆，要撐過 12 個月，而且：

- 😈 **慣老闆指數**不能到 100，不然會上新聞
- 💰 **現金**月底不能是負的，不然公司會倒閉
- 👥 **員工**不能全部跑光

太佛心會倒閉，太摳會變慣老闆。做選擇時你只看得到要花多少錢，員工心裡怎麼想，選了才知道。

## 怎麼玩

直接用瀏覽器打開 `index.html`，不用安裝任何東西。

**每個月就是一個上班日。** 從早上 9 點到下午 6 點，時鐘會一直跑（現實時間大約 3 分鐘）。你要在辦公室裡走來走去處理事情：

- 員工頭上冒出 **!**：有事找你（要求加薪、懷孕、發燒、被奧客罵哭……）
- ☎️ **電話響了**：投資人、總部、供應商、房東
- 🚪 **門口有人**：房東、奧客、爆紅湧進來的客人

泡泡外圈是倒數計時，拖太久就算你**無視**：員工會覺得被冷落，電話沒接會損失錢。

老闆自己也要顧身體：

- ⚡ **精力**：一直在掉，低於 20 走路變慢，歸零會當場昏倒，當天剩下的事全部沒人處理
- 🍱 **肚子**：太餓精力會掉得更快
- 到 ☕ 咖啡機補精力（越喝越沒效）、🍱 冰箱吃便當、🛋️ 沙發睡午覺（睡覺時時間照跑，事件不會等你）

| 操作 | 電腦 | 手機 |
| --- | --- | --- |
| 移動 | WASD／方向鍵，Shift 跑步 | 點地圖，會自己走過去 |
| 互動 | E／空白鍵 | 點目標，或按「E 互動」 |
| 選擇 | 數字鍵 1～4 | 點選項 |
| 暫停 | P | ⏸ 按鈕 |

每天上班前會先看一張 📋 **交接單**（本月新聞）；下班後看 📊 **月報表**，再調整售價、薪資、加班政策、福利、招人或資遣。

| 難度 | 說明 |
| --- | --- |
| 普通模式 | 每天約 3 件事 |
| 🔥 爆肝模式 | 每天約 4 件事，精力掉得比較快 |

目前有 5 種產業，各有專屬事件：

| 產業 | 特色 |
| --- | --- |
| 🧋 手搖飲店 | 夏天旺季、打烊清潔算不算工時、奧客 |
| 💻 科技新創 | 假責任制、投資人 Demo、畫大餅給股票 |
| 🏪 便利商店 | 大夜班、偽鈔扣薪、強迫認購年菜 |
| 🍜 餐廳 | 廚房冷氣、國定假日加倍、服務費 |
| 📚 補習班 | 家長半夜 LINE、競業禁止、假承攬 |

月底結算時，士氣太低會有人離職，慣老闆指數越高越容易被勞檢。選了比較「慣老闆」的選項後，會跳出勞動法小知識（勞基法、性別平等工作法等）。

### 物價、油價、電價的時間線

每個月初會出現「📰 本月新聞」，成本會跟著時間慢慢上漲：

| 項目 | 怎麼變 | 影響的成本 |
| --- | --- | --- |
| 📈 物價 | 每月平均漲 0.4%（一年約 5%） | 原物料／食材／教材、員工福利 |
| ⛽ 油價 | 每月隨機波動，偏向上漲，會有油價飆漲事件 | 油資與運輸 |
| ⚡ 電價 | 4 月、10 月電價審議調整（0～11%）；6～9 月是夏月電價 | 水電 |
| 👛 市場薪資 | 每月平均漲 0.4% | 你沒跟著調薪，員工會抱怨、士氣下降、慣老闆指數上升 |

你可以用兩個方法因應：

- **調整售價**：漲價幅度跟上物價，客人不太在意；漲得比物價多 5% 以上，客人會大量流失
- **全員調薪 3%**：每月最多一次，讓薪水追上物價

固定成本會分成四項列出：房租、原物料、水電、油資，各產業的名稱不同，例如便利商店是「水電（冷藏冷凍 24 小時）」，科技新創是「雲端與軟體訂閱」。

## 檔案結構

```
index.html        頁面
style.css         樣式（支援深色模式、手機版）
js/data.js        產業設定、經營方針、違規項目、所有事件
js/engine.js      遊戲邏輯與物價時間線（不碰 DOM，參數在 ECONOMY）
js/world.js       即時辦公室場景：地圖、移動、時鐘、精力與肚子（參數在 MODES、DEADLINE）
js/ui.js          畫面渲染與操作
tools/simulate.js 平衡測試：用不同策略各跑上千局
```

### 新增事件

在 `js/data.js` 的 `EVENTS` 裡加一個物件：

```js
{
  id: 'my_event',
  icon: '🎉',
  title: '事件標題',
  text: '事件描述',
  industries: ['drinks'], // 不填 = 所有產業都會出現
  months: [6, 7, 8],      // 不填 = 每個月都可能出現
  where: 'phone',         // 事件出現的地方：staff（員工，預設）、phone（電話）、door（門口）
  ignore: { effects: { morale: -5, jerk: 5 }, result: '被無視時的結果' }, // 不填就用 IGNORE 裡的預設
  choices: [
    { label: '好老闆選項', effects: { cash: -10000, morale: 5, jerk: -3 }, result: '結果描述' },
    {
      label: '慣老闆選項',
      quote: '慣老闆語錄',
      effects: { cash: 10000, morale: -5, jerk: 8, flag: 'unpaidOT' }, // flag：勞檢時會被罰
      // 其他效果：price（售價 +0.05 = 漲 5%）、costMult: { materials: 0.1 }（某項成本永久 +10%）、
      //          index: { oil: 0.15 }（油價指數 +15%）、wageMult、staff、demand
      result: '結果描述',
      tip: '勞動法小知識',
    },
  ],
}
```

`cash` 以手搖飲店的規模撰寫，其他產業會依 `scale` 自動放大。

### 平衡測試

```
node tools/simulate.js 1000      # 普通模式（每月 3 件事）
node tools/simulate.js 1000 4    # 爆肝模式（每月 4 件事）
```

會用「永遠最佛心」「永遠最摳」「照行情」「看情況」「隨機」幾種策略各跑 1000 局，列出每種產業的勝率和結局分布（自動測試不會無視事件，只測經營數值）。

辦公室地圖在 `js/data.js` 的 `MAP`，用文字畫的，改字元就能改格局。

> 遊戲裡的法規說明只是簡化的科普，實際狀況請以勞動部公告和專業諮詢為準。
