# 😇 不當慣老闆模擬器

開一間台灣街頭的小店：自己擺設、自己排班、自己定價。讓客人吃飽、員工開心，還要記得付房租。

沙盒經營遊戲，沒有時間限制。只要**慣老闆指數到 100**（上新聞），或是**現金是負的又借不到錢**，店就會收起來。

直接用瀏覽器打開 `index.html` 就能玩（3D 畫面需要連網載入 three.js，存檔存在瀏覽器裡）。

## 怎麼玩

**店面是一個 3D 的台灣街景**：騎樓、停在路邊的機車、隔壁店家的鐵捲門、你的招牌。拖曳移動視角、滾輪（或兩指）縮放、Q／E 旋轉；靠近鏡頭的牆會自動降低。天色會從白天變黃昏，晚上街燈和招牌會亮。

**客人是真的走進來的人**：路過的人會依照評價、價格、店面漂亮程度決定要不要進來；進來後點餐、排隊、被服務、付錢（頭上跳出金額），可以內用的店會找位子坐。等太久會生氣離開，留下一星評論。

**員工有自己的想法**：每個人有個性（勤勞、愛聊天、新手、老手、玻璃心、吃貨、夜貓子、開朗）、技能、心情、精力、飽足感。累了會自己去休息區；沒有休息區只能站著撐。頭上會冒出想法：「好累……」「加班費到底有沒有……」「老闆人很好」。點員工可以加薪、稱讚、罵人、叫他先下班、資遣。

| 分頁 | 可以做的事 |
| --- | --- |
| 🏗️ 建造 | 買設備、座位、等候區、陳列、員工休息區、裝潢（盆栽、招財貓、土地公神桌、冷氣、魚缸……）；搬動、旋轉、賣掉；擴建成中店面、大店面 |
| 👥 員工 | 看每個人的狀態和班表；每週有新的應徵者 |
| ⚙️ 經營 | 營業時間、一天幾班、公休日、輪休、加班費、休息；每個品項的價格和要不要賣；跟銀行借錢 |
| 📊 帳本 | 這週的收支、每週淨利圖、物價／油價／電價、新聞 |
| ⭐ 評論 | 評價和客人的留言 |
| 🏙️ 成長 | 店家等級、即將解鎖的東西、分店、年度評選、成就 |

每週結算一次（週報），每四週是一個月：物價、市場時薪會上漲，4 月和 10 月電價審議，6～9 月是夏月電價。

**台灣生活感**
- 天氣：晴天、炎熱、陰天、寒流、下雨、颱風。下雨天客人少、外送多，路人會撐傘；颱風天要決定要不要營業。
- 節慶：過年前（大家要剪頭髮、保養機車）、春節連假、母親節、端午、中元普渡、開學季、中秋烤肉、跨年。國定假日出勤，工資自動加倍。
- 外送平台（早餐店、麵店、手搖飲）：外送員騎著有外送箱的機車來取餐，訂單比較大，但平台抽成 30%。

**員工人際關係**：一起上班的同事會慢慢變成好朋友或處不來。好朋友同班心情比較好；合不來的會吵架，要你出面調解或把他們排開；感情很好的可能會在一起；好朋友離職，留下來的人也會難過。

**長期目標**
- 店家等級：賺的毛利越多經驗越高，升級解鎖高級設備（雙層大煎台、自動煮麵機、自動茶飲機、電動理髮椅、油壓升降台、自助結帳機）、更多裝潢和更大的店面。
- 展店：Lv.5 之後可以在板橋、新莊、台中、台南、高雄等地開分店，分店收入看本店的評價和慣老闆指數。
- 年度好店評選：每年 12 月最後一週頒獎，金銀銅獎有獎金；慣老闆指數太高會被網友票選為「年度慣老闆」。

**音效與音樂**：收銀機的叮聲、進門門鈴、客人生氣、事件提醒、升級，還有街道背景音、雨聲和背景音樂，全部用瀏覽器即時合成；右上角可以分別關掉音樂和音效。

**慣老闆指數**會因為這些事上升：加班不給加班費、不排休（七休一）、不准休息、沒有休息區、薪水低於行情、罵員工、事件裡選了慣老闆的選項。指數越高越容易被勞檢罰錢。

員工偶爾會有事找你（頭上出現 **!**，左上角也會列出來），電話會響、門口會有人。有些事可以「🎮 老闆親自下場」玩小遊戲解決。

| --- | --- | --- |
| 移動視角 | 拖曳 | 拖曳 |
| 縮放／旋轉 | 滾輪／Q、E | 兩指縮放／右下角按鈕 |

## 檔案結構

```
index.html          頁面
style.css           樣式（深色模式、手機版）
js/industries.js    產業、品項、設備與家具目錄、店面大小、員工個性
js/sim.js           模擬核心：尋路、客人與員工的行為、排班、財務、事件、存檔（不碰 DOM）
js/data.js          事件、違規項目
js/portraits.js     角色外觀與 SVG 立繪
js/people3d.js      Q 版 3D 小人
js/shop3d.js        3D 店面與街景、設備模型、日夜、鏡頭、建造預覽
js/minigames.js     老闆親自下場的小遊戲
js/audio.js         音效與背景音樂（WebAudio 即時合成）
js/ui.js            介面
tools/run-sim.js    無畫面跑模擬，檢查每個產業的營收和成本
```

```
node tools/run-sim.js 14            # 每個產業用預設配置跑 14 天
node tools/run-sim.js 14 breakfast  # 只跑早餐店
```

### 新增產業或設備

在 `js/industries.js` 加一個產業（品項、尖峰時段、預設擺設），再到 `CATALOG` 加它用的設備：`serves` 是能做的品項，`staff`／`cust` 是店員和客人站的位置（以設備正面為前方的相對座標）。3D 模型在 `js/shop3d.js` 的 `MODELS` 裡用方塊和圓柱拼出來。

> 遊戲裡的法規說明只是簡化的科普，實際狀況請以勞動部公告和專業諮詢為準。
