# RO 倖存者非營利同人研究結論與遊戲設計規格

本作要把 RO 的職業、怪物、地圖、裝備、卡片與寵物放進倖存者玩法，同時保留三個被玩家反覆肯定的結構：具有詠唱、冷卻與定位差異的職業戰鬥；每局十來分鐘內形成的隨機構築；以及裝備、天賦、卡片與寵物帶來的長期養成。官方素材由使用者本機 GRF 載入；程式、平衡表、後端與介面自行重寫。

# 研究結論

## 作品與版本判定

- `RO Survivors` 是 Reven4nt 製作的非官方同人網頁遊戲，唯一官方入口為 `https://ro-survivors.com/`。
- `ro.hans-webgametw.com` 是 HANS 另行改作與營運的版本。HANS 的 Credits 自己標示它改作自 RO Survivors；原作者的法律頁則說明沒有授權其他站點複製、改作或另行架站。
- 原作截至 2026-11-16 約為 Beta 0.7.2；HANS 功能擴張速度更快，已加入八人組隊、拍賣、擺攤、三轉、PVP、公會、六周目、升星與洗鍊等。這些是長期功能清單，不是合理的首版範圍。
- 原作 Credits 公開的技術包括 TypeScript、Vite、PixiJS、Three.js 與 Node.js，並明載 Claude 參與程式、文字與工具撰寫。真正的設計、取捨、平衡與測試仍由人持續完成。

## 玩家喜歡的部分

- 技能有冷卻、詠唱、屬性、範圍與職業差異，因此有 MMO 職業感，而不是只換美術的割草遊戲。
- 局內三選一與局外裝備、天賦、卡片形成兩層成長，每一局都有短期與長期目的。
- 等角或 2.5D 視覺、像素角色與城鎮廣場比全 3D 手遊更能喚起老玩家情緒。
- 網頁開啟即可玩，手機直向、電腦與手把都有入口，降低嘗試成本。
- 看得到其他玩家、組隊、聊天與交易能提高黏著，但不是核心戰鬥成立的前提。

# 同人版產品定位

## 一句話說明

一款可在手機與電腦瀏覽器遊玩的非營利 RO 2.5D 倖存者 RPG：玩家以走位應對怪潮與 MVP 預警，在每局形成職業流派，並把獲得的裝備、卡片與天賦帶回普隆德拉長期培養。

## 不做的事

首版不做以下功能：

- HANS 或 RO Survivors 的程式、資料、文案、數值表或網路協定相容
- 把 GRF、SPR、ACT、BGM 或音效提交到公開 Git 儲存庫
- 冒充 Gravity、台灣營運商或 Reven4nt 官方版本
- 八人組隊、PVP、公會戰、拍賣、離線擺攤、轉生、升星、洗鍊與六周目
- 付費抽卡、戰力販售、廣告中斷或現金交易
- 在核心戰鬥穩定前建立公開經濟

# 核心遊戲循環

```text
城鎮整備
  → 選角色、裝備、關卡與難度
  → 10 分鐘怪潮，自動攻擊、玩家走位
  → 撿取經驗，三選一形成技能構築
  → 菁英、事件、小頭目與首領
  → 結算永久經驗、裝備與製作材料
  → 分配素質與天賦、整理裝備
  → 解鎖下一關或提高難度
```

## 單局時間軸

垂直切片使用固定種子可重播的 10 分鐘關卡，另給首領最多 2 分鐘：

| 時間 | 事件 | 設計目的 |
| --- | --- | --- |
| 0:00–0:30 | 緩衝期、低密度敵人、第一個升級 | 讓玩家熟悉移動並保證成形 |
| 0:30–2:00 | 第一波怪群與射手 | 驗證近距與遠距威脅的走位 |
| 2:00 | 第一隻菁英 | 教學寶箱與一次明確獎勵 |
| 3:00–4:30 | 環境事件與敵群混編 | 迫使玩家調整路線 |
| 5:00 | 小頭目 | 檢查單體輸出及預警理解 |
| 6:00–8:30 | 高密度波次與第二菁英 | 驗證流派是否已形成 |
| 9:00 | 首領警告、掉落磁吸加強 | 收束場上資訊、準備決戰 |
| 10:00 | 關底首領 | 同時檢查清怪、單體與生存 |
| 12:00 | 狂暴場地壓力 | 防止無限拖延，不做無法閃避的瞬殺 |

## 操作

- 電腦：WASD、方向鍵、點地移動；滑鼠操作選卡與介面。
- 手機：浮動虛擬搖桿；可切固定搖桿；安全區域適配瀏海與系統手勢。
- 手把：左搖桿移動、方向鍵或右搖桿選卡、A 確認、B 關閉、Start 暫停。
- 普攻與主動技能依射程、目標規則、冷卻及詠唱自動施放。
- 暫停只在單人有效；多人選卡階段改為個人短暫無敵與不吸引新仇恨。
- 所有輸入都轉成同一份 `InputCommand`，遊戲邏輯不得直接讀鍵盤、觸控或手把 API。

# 垂直切片內容

## 職業 劍士

劍士是中速、近中距、容錯較高的入門職。核心不是站樁挨打，而是在防禦、蓄力與範圍清怪之間取捨。技能名稱沿用 RO 名稱，數值與倖存者化效果重新設計並記錄來源版本。

初始基礎：

- 生命 140
- 移動速度 4.8 公尺／秒
- 基礎護甲 8%
- 普攻間隔 0.75 秒
- 普攻為前方短扇形斬擊，可同時命中少量敵人

八個核心能力候選；基本斬擊不佔欄位，主動與被動依 `handoff/vertical-slice-content-seed.json` 分類：

1. `基本斬擊`：自帶的前方短扇形攻擊，不佔主動欄。
2. `狂擊`：朝最近敵人重擊，強化後增加目標與暈眩機率。
3. `怒爆`：以自身為中心造成火屬性範圍傷害，是前 60 秒的清群保證。
4. `霸體`：短時間抗擊退並降低受傷，不能完全無敵。
5. `挑釁`：標記附近敵人、降低其防禦，同時讓接近速度略升，形成風險報酬。
6. `盾牌震波`：若裝備盾牌，向前方發出扇形震波；不會自動移動角色。
7. `致命爆裂`：長冷卻蓄力斬，對菁英與 MVP 有較高破甲。
8. `自動狂暴`：低生命時提高傷害與移速，同時增加承受傷害。

四個首版被動池為 `單手劍使用熟練度`、`雙手劍使用熟練度`、`快速回復` 與 `移動時恢復`。兩手武器和盾牌能力互斥，選項必須先顯示失去的能力。

每局最多裝備 4 個主動能力與 4 個被動能力。升級時從 3 張卡中選 1 張；卡片必須標示具體變化，不能只寫「大幅提升」。

三個流派關鍵選擇：

- `守護`：盾牌、霸體與反擊，犧牲部分移速。
- `武器`：雙手劍與破甲，強化單體及前方攻擊。
- `狂怒`：怒爆與範圍清怪，首領單體較弱。

關鍵選擇是本局不可逆的玩法改造，選擇前必須顯示完整影響並再次確認。

## 關卡 普隆德拉原野

關卡從本機素材庫選定一張普隆德拉周邊地圖，經白名單轉檔後使用。草地、樹木、水岸與道路必須和碰撞一致；小型裝飾物預設沒有碰撞，只有輪廓清楚的大型障礙物會阻擋。

首批魔物候選：

- 波利：標準近戰追逐者。
- 土波利：較慢但生命較高。
- 綠棉蟲：直線接近，死亡時有低機率留下減速黏液。
- 瘋兔：高移速、低生命的小群體。
- 蒼蠅：不規則接近，提醒玩家處理側翼。
- 樹精：低速遠程，發射可讀性高的種子彈。
- 搖滾蝗蟲：週期性跳躍並顯示落點。
- 曼陀羅魔花：固定位置、遠程攻擊，形成路線障礙。
- 蝗蟲：成群移動，提供密度。
- 小野豬：停頓預警後直線衝鋒。

菁英使用普通敵人的可辨識強化版，不只放大體型與血量。每種菁英最多增加一個新機制，並保留原型輪廓。

小頭目使用菁英波利或波波利變體。關底 MVP 使用 `Mastering`，具有跳躍落點、召喚波利、環形彈跳與短暫硬化；硬化期間近戰仍有安全的側後輸出窗口。技能時間軸與碰撞由本作自行設計，不照抄其他同人版本。

# 成長系統

## 局內成長

- 局內等級每局重置。
- 經驗物件使用合併與磁吸，不讓地面生成無上限物件。
- 每次升級提供 3 個有效選項；內容系統要避免全部都是當前流派無法使用的卡。
- 新技能優先填滿主動欄；欄位滿後只出現現有技能強化、被動與流派改造。
- 重抽、放逐與跳過屬於帳號成就解鎖，不在垂直切片一開始全部開放。
- 寶箱不直接複製其他作品的費用公式。首版每場最多 4 個，使用局內金幣開啟並從獨立獎池抽取消耗品或能力改造。
- 低血量保底掉落採「隱藏憐憫值」，但不能保證每次擊殺掉補品，以免被玩家精確利用。

## 局外成長

同人版使用 RO 六項屬性：

| 屬性 | 影響 |
| --- | --- |
| STR | 近戰與物理技能基礎傷害 |
| AGI | 攻擊節奏、少量冷卻恢復與移動手感 |
| VIT | 生命、補品效果與受擊恢復 |
| INT | 法術威力、狀態持續與資源效率 |
| DEX | 遠程傷害、詠唱、投射物速度與命中穩定性 |
| LUK | 暴擊、狀態抵抗與少量掉落品質權重 |

所有收益使用可見的遞減曲線。角色面板要顯示投入前後的實際結果，並允許在城鎮免費重置直到正式經濟上線。

職業等級提供天賦點。每職三條天賦分支，每投入 5 點解鎖下一層；首版每個節點只做一個明確作用，最深層才改變玩法。

## 裝備

MVP 使用六個部位：武器、護具、頭飾、護符、靴子、戒指。

每件裝備包含：

- 全域唯一 ID
- 內容模板 ID
- 掉落來源、時間、關卡、種子與帳號
- 等級、品質、固定特色與隨機詞綴
- 插槽、精煉值、綁定狀態與目前裝備者
- 資料版本與簽章

品質只改變詞綴數量及範圍，不讓低品質物品完全失去特色。精煉在公開經濟上線前不永久毀損物品；先採材料累積與保底進度，等玩家理解成本後再測試風險機制。

## 卡片與寵物

魔物卡片由對應魔物低機率掉落，可裝入指定部位並提供一條可讀能力。卡片能力參考 RO 主題，但轉成倖存者可理解的效果；拆卡要有明確成本，不使用容易誤觸的不可逆操作。

寵物蛋由對應魔物掉落。寵物首版只提供拾取、標記或小幅功能性能力，不做主要戰力來源。親密度來自完成關卡，不鼓勵掛機。

# MVP 與後續內容

## MVP

- 劍士、魔法師、弓箭手
- 3 張 8 至 10 分鐘關卡
- 3 個關底首領、6 個小頭目、至少 18 種普通敵人
- 約 24 個主動技能、18 個被動、9 個流派關鍵選擇
- 約 40 件裝備、18 張卡片、6 隻寵物
- 城鎮選單、角色欄、天賦、裝備、百科與成就
- PWA、離線單人、本機存檔、繁中與英文

## MVP 後

1. 帳號與雲端存檔。
2. 每日／每週挑戰與非付費外觀。
3. 專用房間伺服器的三人合作。
4. 可見玩家的城鎮廣場、好友與組隊媒合。
5. 排行榜與可重播驗證的塔型模式。
6. 只有在物品履歷、風控與管理後台完成後，才考慮有限交易。
7. 拍賣、擺攤、公會、PVP 與賽季屬長期選配，不列入第一年最小承諾。

# 平衡與內容原則

- 先抬升無效流派，再削弱過強流派；避免讓玩家只感受到失去。
- 標準難度下，三種受支持流派的通關率目標差距不超過 10 個百分點。
- 首領中位擊殺時間應落在 60 至 120 秒；任何常見流派若低於 20 秒或超過 180 秒都要檢查。
- 任何職業不得只靠站立不動就穩定通關標準難度。
- 近戰、遠程與法術都必須能在首領每個階段找到輸出窗口。
- 畫面尺寸只影響看見多少，不影響鎖敵、生成、射程、碰撞與掉落。
- Wiki、tooltip、戰鬥數值與更新紀錄由同一份內容資料生成，避免版本互相矛盾。
